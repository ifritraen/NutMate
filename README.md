# NutMate

A premium, privacy-focused sexual wellness, habit tracker, and recovery analytics app built with Flutter.

## Features
- **Session Tracking**: Track Masturbation, Edging, and 🔥 Arousal sessions.
- **Detailed Metrics**: Pre-Nut, Session, Post-Nut recovery habits, Stimulus selector, and backdating options.
- **Analytics & Personal Bests**: Streak tracking, heatmap calendar, personal records, and top triggers/stimuli.
- **Privacy First**: Local SQLite storage, biometric & PIN lock security.
